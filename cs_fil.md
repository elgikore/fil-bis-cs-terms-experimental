# Basic Terms
* **Kagamitan** = Utility
* **Kasangkapan** = Library
    * Using the "collection" reading of *ka- -an* and sangkap implies ingredients
* **Sanggamitan** = Framework
    * Sangkagamitan -> Sanggamitan

# Data Science/ML
* **Datos** = Data
* **Datosan** = Dataset
* **Sandatosan** = Data Center
* **Talaorasan** = Time Series
* **Pagpapatalaorasan** = Time Series Analysis

# Virtualization
* **Birtwalisasyon** = Virtualization
* **Nilahatang Birtwalisasyon** / **Binirtwalisasyon** = Full Virtualization
* **Kabirbirtwalisasyon** = Paravirtualization
    * *Para-* = Alongside and in active involment
* **Sangbirtwal** = Sandbox
    * *Sang-* is used to cover the idea of a bounded virtualized area, but not just a generic virtual-space
* **Kernel**
    * As is; pronounciation does heavy lifting
* **Kernelan** = Kernel Space
